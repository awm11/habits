# Daily Awesomeness

A big-button daily habit tracker that installs on your phone and works offline.

## Put it online with GitHub Pages

1. Create a new repository (for example `habits`) and upload everything in this folder, keeping the `icons` folder.
2. In the repository, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
3. After a minute it's live at `https://<your-username>.github.io/habits/`.

## Install it on your phone

1. Open that address in Chrome on your phone.
2. Tap the **⋮** menu, then **Install app** (or **Add to Home screen**).
3. It now opens from its own icon, full screen, and works without a signal.

## Your data

Everything is stored on the phone, inside the app. Nothing is sent anywhere.

- **Back up:** Habits tab → **Save backup file**. The file goes to your Downloads; keep a copy somewhere safe such as Google Drive.
- **Restore or move phones:** Habits tab → **Restore from file**, or paste a copied backup.
- Clearing Chrome's site data for the address, or uninstalling the app, deletes what's stored, so back up first.

## Updating

Replace `index.html` in the repository with a new version. The app picks it up the next time it's opened with a signal.
